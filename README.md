# 📊 Social Media Impact on Life — Power BI Dashboard

## 📌 Project Overview
This project explores social media usage patterns and their relationship with sleep duration, age groups, and device preferences using an interactive Power BI dashboard.

## 🎯 Objectives
- Analyze social media platform popularity.
- Explore daily screen time and sleep duration.
- Compare usage across different age groups.
- Understand device preferences.
- Present insights through interactive visualizations.

## 🛠️ Tools Used
- Microsoft Power BI
- Data Analysis
- Data Visualization
- Interactive dashboards and slicers

## 📈 Key Insights
- Instagram is the most popular primary platform in the displayed dataset.
- Smartphones account for the largest share of device usage.
- Teenagers contribute more total daily usage hours than adults in the displayed dataset.
- The dashboard explores the relationship between daily usage hours and sleep duration.

## 📊 Dashboard Preview
The dashboard includes KPI cards, platform popularity, daily usage, device distribution, usage versus sleep, late-night impact, and screen time by age group.

## 💡 Learning Outcomes
Practiced dashboard development, KPI creation, interactive filtering, chart design, and communicating data-driven insights.
